The operator profile is imported by the user-level `~/.claude/CLAUDE.md`
on the machine that carries it; on a machine without that import, add
`@<path to your OPERATOR-PROFILE.md>` there, not here, so a project's
stamped copy never shadows the live one. What a session does at its
opening and on a first message of `start` is in PROJECT-INSTRUCTIONS.md,
"Claude Code sessions". Anything this project adds for its sessions goes
in PROJECT-PROFILE.md, which is imported above.
